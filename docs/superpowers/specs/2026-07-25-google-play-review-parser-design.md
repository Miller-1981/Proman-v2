# Парсер отзывов Google Play: дизайн

Дата: 2026-07-25

## Цель

Создать локальное Windows-приложение для пользователя без опыта программирования. Пользователь вставляет ссылку Google Play или package ID, выбирает страну, язык, количество отзывов, сортировку и фильтр по рейтингу, затем получает CSV-файлы с отзывами для дальнейшего анализа.

Первая версия не включает AI-анализ, перевод, App Store, авторизацию, облачный сервер, базу данных, PDF/DOCX-отчеты и сравнение нескольких приложений.

## Рекомендуемый подход

Проект будет обычным Streamlit-приложением на Python в папке `google-play-review-parser`. Запуск для пользователя выполняется через `install.bat` и `run.bat`; сборка в `.exe` в первую версию не входит.

Структура:

```text
google-play-review-parser/
├── app.py
├── scraper.py
├── utils.py
├── requirements.txt
├── README.md
├── install.bat
├── run.bat
├── exports/
└── .gitignore
```

## Компоненты

`app.py` содержит Streamlit-интерфейс на русском языке: поля ввода, кнопка скачивания, прогресс, статусы, статистика, предпросмотр первых 50 отзывов и кнопки скачивания CSV.

`scraper.py` отвечает за интеграцию с `google-play-scraper`: получение информации о приложении, скачивание отзывов пакетами, преобразование сортировки и базовую обработку ошибок библиотеки.

`utils.py` содержит независимые функции: извлечение package ID из ссылки, очистку текста, форматирование дат, определение языка, удаление дублей, фильтрацию по рейтингу и подготовку CSV в кодировке `utf-8-sig`.

`exports/` хранит локальные копии CSV-файлов после успешного скачивания. Файлы также доступны через download-кнопки в Streamlit.

## Поток Данных

1. Пользователь вводит ссылку или package ID.
2. `utils.py` извлекает и валидирует package ID.
3. `scraper.py` получает app info через `google_play_scraper.app`.
4. `scraper.py` скачивает отзывы через пагинацию `google_play_scraper.reviews`.
5. `utils.py` нормализует строки, даты, языки, удаляет пустые отзывы и точные дубликаты.
6. `app.py` показывает статистику и таблицу предпросмотра.
7. Приложение создает четыре CSV-файла:
   - `reviews_APPID_DATE.csv`
   - `negative_reviews_APPID_DATE.csv`
   - `positive_reviews_APPID_DATE.csv`
   - `app_info_APPID_DATE.csv`

## Интерфейс

Поля интерфейса:

- ссылка или ID приложения;
- страна Google Play с вариантами `us`, `gb`, `in`, `pk`, `ng`, `br`, `de`, `fr`, `es`, `it`, `ru` и ручным вводом;
- язык Google Play с вариантами `en`, `ru`, `pt`, `es`, `de`, `fr`, `it`, `hi` и ручным вводом;
- количество отзывов с вариантами `100`, `300`, `500`, `1000`, `3000`, `5000` и ручным вводом;
- сортировка: самые новые, самые полезные, по рейтингу;
- фильтр по рейтингу: все оценки, 1, 2, 3, 4, 5, 1-3, 4-5.

После скачивания интерфейс показывает app info, счетчики по рейтингам, количество ответов разработчика, частые языки и таблицу первых 50 отзывов. Переключатель "Показать только негативные отзывы" фильтрует предпросмотр.

## Ошибки

Пользователь видит понятные сообщения на русском языке:

- не удалось определить ID приложения;
- приложение не найдено;
- Google Play временно не отвечает;
- скачано меньше отзывов, чем запрошено;
- нет текстовых отзывов для выбранного фильтра.

Техническая ошибка может печататься в терминал для диагностики, но не должна заменять пользовательское сообщение в интерфейсе.

## Тестирование

Проверка идет этапами:

1. Структура проекта, `install.bat`, `run.bat`, импорт модулей.
2. Извлечение package ID из ссылки и прямого ID.
3. Получение app info для реального приложения Google Play.
4. Скачивание отзывов с пагинацией.
5. Очистка текста, удаление дублей, определение языка и сохранение эмодзи.
6. Streamlit-интерфейс и кнопки скачивания.
7. Проверка минимум на двух реальных приложениях Google Play.

Live-проверки и установка зависимостей требуют интернет-доступа.
